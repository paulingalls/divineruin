# apps/agent — Python DM agent

## Python test lanes (placement by directory)

- **Fast lane** — everything under `apps/agent/tests/` *except* `tests/acceptance/`. Proof task `agent-pytest` (`bunx proof run --set land`). Holds pure-logic tests **and** simple real-PG tests against the shared dev DB at `:55432` — `tests/conftest.py` auto-starts docker compose if it's down (fail-loud if Docker is absent; tests are never silently skipped). Real-PG tests here isolate via unique keys + cleanup (see the `_db_lifecycle` / `dev_db_pool` pattern). Put a real-PG test here when it's a single-table / single-concern round-trip.
- **Acceptance lane** — `apps/agent/tests/acceptance/` only (marker auto-applied by directory). One Proof task per file, `agent-acceptance:<file stem>` (`bunx proof run --set sprint`, or `--tasks`; sprint close, free-patch Acceptance and the scheduled super run go through Proof too). **Paid provider tests (`real_llm`, `openai_real_llm`, `live_voice` markers) are always skipped** — hooks, the sprint full tier and the super run included — unless a human approves a specific run: `ALLOW_PAID_TESTS=1 REQUIRE_REAL_LLM=1 uv run pytest <file>` (`tests/_paid_tests.py`, human 2026-09-22). Never put `ALLOW_PAID_TESTS` in `.env`. Per-run **testcontainer** Postgres + LiveKit dev-server. Put a test here when it's a multi-system / LiveKit / end-to-end capstone needing per-run isolation.
