# Audio Assets (source SSOT)

This directory is the repo source-of-truth for generated audio. Bundled client
copies live in `apps/mobile/assets/sounds/`; the repo (source + generator +
prompts) is the SSOT so every asset is **regenerable from a written prompt**
(`docs/audio_design.md` Fifth Principle, "Audio Must Be Generatable").

## `spell_sfx/` — M17 spell-cast SFX palette

The frozen 7-key source-by-effect palette (`docs/audio_sfx_pipeline.md` §4):
`spell_fire`, `spell_ice`, `spell_arcane_force`, `spell_heal`, `spell_radiant`,
`spell_nature`, `spell_generic`. One `.mp3` per key (2s, 44.1kHz, 128kbps —
transcoded from the SA3 model's raw Int16 PCM WAV output). story-003 maps each
spell's `sound_id` to one of these keys and wires the
client registry; story-004 emits `PLAY_SOUND(sound_id)` deterministically on cast.

### Engine — Stable Audio 3.0 Small SFX (chosen via bake-off)

Generated by **`stabilityai/stable-audio-3-small-sfx`** — an open-weight,
SFX-specialized model run locally (MPS/CPU, no GPU). Chosen over ElevenLabs via a
listening A/B bake-off (same 7 prompts through both engines): the free
open-weight Stable Audio set cleared the quality bar, so no paid subscription is
needed. (An ElevenLabs generator, `scripts/audio/generate_spell_sfx.py`, remains
in-repo as the alternative engine and as the prompt-table SSOT that both
generators import.)

### Regenerate

The generator (`scripts/audio/generate_spell_sfx_stableaudio.py`) holds no
prompts of its own — it imports the frozen `PROMPTS` table from
`generate_spell_sfx.py`. It needs the `stable-audio-3` package in a **dedicated
venv** (not a repo dependency) and a HuggingFace token with the model's gated
terms accepted. Bootstrap the env reproducibly from the repo (pinned
`stable-audio-3` commit, gitignored venv path — no ad-hoc temp folders):

```bash
scripts/audio/setup_sfx_env.sh                 # one-time: venv at scripts/audio/.venv-sa3
# accept gated terms at https://huggingface.co/stabilityai/stable-audio-3-small-sfx (once)
scripts/audio/.venv-sa3/bin/python scripts/audio/generate_spell_sfx_stableaudio.py \
  --out-dir apps/audio/spell_sfx
```

Text-to-audio is generative, so regeneration reproduces the palette via the same
pipeline (model + prompts + params), **not** byte-for-byte. The committed files
are the specific takes signed off in the bake-off; regenerating replaces them
with fresh takes. The generator renders Int16 PCM WAV, then transcodes to
`.mp3` (128kbps, via ffmpeg) and removes the intermediate WAV — the default
`--format mp3` path. `--format wav` keeps the raw SA3 output if needed.
