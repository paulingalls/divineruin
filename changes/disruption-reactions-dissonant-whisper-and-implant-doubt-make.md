Bump: minor

- Bards can spend 2 Focus on Dissonant Whisper. An attacker that fails its Wisdom save rolls the triggering attack with disadvantage.
- Whispers can spend 2 Focus on Implant Doubt after an enemy attack hits. If the attacker fails its Wisdom save, it rerolls at disadvantage and keeps the replacement.

After deploying the code and before starting the new agent processes, run `SEED_PRODUCTION=1 bun run seed` from the deployed repository root with the production environment.
