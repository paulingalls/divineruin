Bump: minor

Aelora’s artificers, bards and diplomats gain +1 from Common Bond on live
Crafting checks, recipe experiments and newly started crafting projects. Common
Bond stacks with Craft Blessing.

Before starting the updated services, run `SEED_PRODUCTION=1 bun run seed` from
the release checkout with the production deployment environment loaded. This
command writes the patron catalog to the production database.
