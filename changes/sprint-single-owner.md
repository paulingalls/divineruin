Bump: minor

Each agent event and each shared game calculation now has one owner, so the HUD and the DM hear the same numbers everywhere.

When a social check, a quest or the session changes an NPC's disposition, your companion names who it was. Before, it sometimes said "someone". Intimidating or persuading an enemy creature in combat now works; before, it was refused as an unknown NPC.

Every dice roll reaches the overlay with its real roll, modifier and total, including Choir searches, de-escalation, travel, gathering and death saves. Saving-throw receipts carry their rally, oath and override details from the save itself, and every session snapshot carries the session's real time of day.

Skill checks now get first stay, terrain and season from one place, so gathering, travel, social, Choir, Still and de-escalation rolls gain the seasonal bonus they were missing. Queued crafting and experiments roll with the same Arcana modifier as a live check, read when the work settles, so a condition picked up after queueing counts and a live ally changes an experiment the way it changes a live check.

A spell that drops the last enemy gets the last-enemy moment a weapon would, and a spell that opens a fight gets the first-attack moment. A second Cleave swing on the last foe now gets the last-enemy moment too. Combat uses one rule for whether a participant is standing. Gold toasts carry the exact amount and balance the purse changed by, and divine favor, ability save DCs and de-escalation Focus use the same rules everywhere.

A new code check refuses any publisher that hand-builds one of these events instead of using its builder.

Release steps: none.
